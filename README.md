# Leno-website-BEM

This repository contains the code for the Leno App website, a practice project focused on building an informational product page while adhering to the BEM (Block, Element, Modifier) methodology for CSS.

## Project Description

The Leno App website is designed to showcase a product aimed at boosting health and productivity. It features a clean, modern design with sections dedicated to highlighting key features, providing testimonials, showcasing a preview with a video integration, detailing the app's functionalities, and offering download links. This is just all information as everything is static.

## Key Features

*   **Responsive Design:** The website adapts seamlessly to various screen sizes, ensuring a consistent user experience across devices.
*   **BEM Methodology:** CSS is structured using the BEM methodology for better maintainability and scalability.
*   **Interactive Elements:** Includes features like a mobile menu toggle and a video modal for an engaging user experience.
*   **Clear Navigation:** A sticky navigation bar with scroll effects enhances user experience.
*   **Informative Sections:** Dedicated sections for features, testimonials, preview, details, and download information.
*   **Font Awesome Integration:** Utilizes Font Awesome for icons throughout the site.
*   **Smooth Scrolling:** Implemented for enhanced navigation between sections.

## Tech Stack

*   **HTML5:** For structuring the web content.
*   **CSS3:** For styling and layout, with adherence to BEM methodology.
*   **JavaScript:** For interactive elements and dynamic behavior.
*   **Google Fonts:** For typography (`Open Sans`).
*   **Font Awesome:** For icon integration.

## Usage

The Leno App website serves as a portfolio piece demonstrating the implementation of BEM CSS and front-end development skills. It's structured to be a single-page application, with navigation links directing users to different sections of the `index.html` page.

## Project Structure

```
Leno-website-BEM/
├── index.html
├── details.html
├── css/
│   └── styles.css
└── js/
    └── script.js
```

*   **`index.html`:** The main landing page of the website.
*   **`details.html`:** A supplementary page detailing features and pricing.
*   **`css/styles.css`:** Contains all the styling for the website, adhering to BEM.
*   **`js/script.js`:** Handles interactive elements like the mobile menu, navbar scroll effects, and video modal.
